# Couple Photographs Guide

This folder holds the couple photographs for David & Monica's Wedding Invitation Website.

### How to use the couple's actual photographs:
1. **Hero Main Photo:**
   - Save the primary couple portrait as `assets/images/couple-hero.jpg` (or `.png` / `.webp`).
   - The website automatically checks and displays `couple-hero.jpg`. If not present, it gracefully falls back to the ornate gold monogram arch illustration.
   
2. **Photo Gallery:**
   - Save the gallery photos as:
     - `assets/images/couple/photo1.jpg`
     - `assets/images/couple/photo2.jpg`
     - `assets/images/couple/photo3.jpg`
     - `assets/images/couple/photo4.jpg`
     - `assets/images/couple/photo5.jpg`
     - `assets/images/couple/photo6.jpg`
   - You can also add more photos by editing `js/gallery.js`.

### Note:
No alterations or modifications to facial features or identities will ever be made. The website preserves the exact authentic high-resolution photos provided.
